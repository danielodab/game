A conta local — o banco de dados que um dia vira servidor

Toda a vida «online» do jogo (moedas, cofre, históricos) passa por JOGO.DB, cuja API é assíncrona DE PROPÓSITO: quando o servidor chegar, troca-se o miolo e nenhum chamador percebe. Esta página cobra as regras — inclusive a de que nenhuma resposta pode chegar síncrona, porque um chamador que dependa disso quebraria exatamente no dia da migração.
